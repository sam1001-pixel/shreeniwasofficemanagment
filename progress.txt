# Progress Log

## Codebase Patterns
- **Database Access**: Relational SQLite database with WAL mode and PRAGMA foreign_keys = ON via Prisma ORM for zero external daemon dependency, complete transaction safety, and instant point-in-time backup portability.
- **Client Google Form Integration**: Live inspected form title is "Shree Niwas Properties & Rentals Property Visit Record". All 13 fields (including Hindi labels and dropdown options with "Other" write-in support) are mapped to database model `ClientFormSubmission`.
- **Daily Update Report**: 9 mandatory English fields preserved verbatim: `Post on Insta`, `Website`, `Visit Pass`, `YouTube Post`, `CHARA`, `VISIT`, `Bhole Shankar Lal Bagh`, `New Property`, `Other Important Updates`. Versioned via `DailyUpdateRevision`.
- **Financial Integrity**: Monetary values handled with 2 decimal places. Soft reversals/adjustments instead of hard deletes on approved transactions. Dynamic "Other" category supported.
- **Excel Automation**: ExcelJS library used server-side with formula injection sanitation (prefixing `=`, `+`, `-`, `@` with single quote `'`).
